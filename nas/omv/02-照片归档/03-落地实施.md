## 落地目标

在 OMV 上部署 Immich，并实现：

- 手机自动备份
- 相机照片导入后自动索引与可搜索
- 外网通过 Cloudflare Tunnel 安全访问

## 1. 前置准备

### 1.1 共享目录

- `/srv/data/photos/library`
- `/srv/data/photos/import`
- `/srv/data/appdata/immich`
- `/srv/data/appdata/compose/immich`

### 1.2 域名规划

- `photos.example.com` → Immich

## 2. 部署 Immich（Docker Compose）

在 `/srv/data/appdata/compose/immich/docker-compose.yml`：

```yaml
services:
  immich-postgres:
    image: postgres:16
    restart: unless-stopped
    environment:
      - POSTGRES_PASSWORD=${DB_PASSWORD}
      - POSTGRES_USER=immich
      - POSTGRES_DB=immich
    volumes:
      - /srv/data/appdata/immich/postgres:/var/lib/postgresql/data

  immich-redis:
    image: redis:7
    restart: unless-stopped

  immich-machine-learning:
    image: ghcr.io/immich-app/immich-machine-learning:release
    restart: unless-stopped
    volumes:
      - /srv/data/appdata/immich/ml:/cache

  immich-server:
    image: ghcr.io/immich-app/immich-server:release
    restart: unless-stopped
    depends_on:
      - immich-postgres
      - immich-redis
    environment:
      - DB_HOSTNAME=immich-postgres
      - DB_USERNAME=immich
      - DB_PASSWORD=${DB_PASSWORD}
      - DB_DATABASE_NAME=immich
      - REDIS_HOSTNAME=immich-redis
    volumes:
      - /srv/data/photos/library:/usr/src/app/upload
      - /etc/localtime:/etc/localtime:ro
```

在同目录创建 `.env`：

```env
DB_PASSWORD=CHANGE_ME
```

启动：

```bash
cd /srv/data/appdata/compose/immich
docker compose up -d
```

## 3. 对外访问（Cloudflare Tunnel）

在 Cloudflare Tunnel 的 Public Hostname 添加：

- Hostname：`photos.example.com`
- Service：`http://immich-server:2283`

同样要求 cloudflared 与 immich 在同一 Docker network，或改成宿主机地址。

## 4. 手机自动备份

- 安装 Immich App
- 登录账号
- 开启自动备份（按需设置仅 Wi-Fi、后台上传）
- 观察上传队列与服务器端照片数量增长

## 5. 相机照片导入（推荐：导入目录 + External Library）

### 5.1 导入目录

电脑把相机照片复制到：

- `/srv/data/photos/import`

复制方式可选：

- SMB 共享（仅内网）
- Nextcloud 同步后再落到 `import/`

### 5.2 Immich 配置 External Library

在 Immich 管理界面中：

- 添加 External Library 指向 `/srv/data/photos/import`
- 开启定时扫描/导入（或手动触发一次扫描）

### 5.3 Tag 与人脸

- 开启/等待后台任务完成
- 在人物页面对人脸进行确认与命名

## 6. 验收清单

- 手机新增照片可自动上传并可搜索到
- 相机导入目录新增照片后可自动出现在时间线
- 人脸识别可用（可创建人物并归类）
- 外网 HTTPS 可访问（可选叠加 Cloudflare Access）

## 7. 备份（必须）

至少备份：

- `/srv/data/photos/library`
- `/srv/data/appdata/immich/postgres`
- `docker-compose.yml` 与 `.env`

建议每月做一次恢复演练（恢复数据库后可浏览照片，索引可重建）。
