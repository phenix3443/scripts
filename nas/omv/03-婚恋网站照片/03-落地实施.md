## 落地目标

为婚恋网站提供稳定的图片访问入口，默认私密（仅你与老婆），可选公开部分图片。

## 1. 前置准备

### 1.1 目录结构

在 OMV 上创建：

- `/srv/data/wedding/private`
- `/srv/data/wedding/public`（可选）
- `/srv/data/appdata/compose/wedding-static`

### 1.2 域名规划

- 私密：`wedding.example.com`
- 公开（可选）：`wedding-public.example.com`

## 2. 部署静态图片服务（Nginx）

在 `/srv/data/appdata/compose/wedding-static/docker-compose.yml`：

```yaml
services:
  wedding-static:
    image: nginx:1.27-alpine
    restart: unless-stopped
    volumes:
      - /srv/data/wedding:/usr/share/nginx/html:ro
```

默认目录映射：

- `private/` → `https://wedding.example.com/private/...`
- `public/` → `https://wedding.example.com/public/...`

启动：

```bash
cd /srv/data/appdata/compose/wedding-static
docker compose up -d
```

## 3. Cloudflare Tunnel 暴露服务

在 Cloudflare Tunnel 的 Public Hostname 添加：

- `wedding.example.com` → `http://wedding-static:80`

如果要单独公开子域名，再增加一条：

- `wedding-public.example.com` → `http://wedding-static:80`

## 4. 配置访问控制

### 4.1 私密（推荐）

在 Cloudflare Zero Trust 配置 Access：

- Application：`wedding.example.com`
- Policy：仅允许你与老婆的邮箱登录（OTP 或 SSO）

### 4.2 公开（可选）

推荐做法：公开子域名，不对其启用 Access。

如果只想公开 `public/` 路径而私密 `private/`，建议：

- `wedding.example.com`：启用 Access（所有路径私密）
- `wedding-public.example.com`：仅用于公开 `public/` 内容
- 网站公开页面只引用 `wedding-public.example.com/public/...`

## 5. 网站侧集成建议

- 私密页面：引用 `wedding.example.com/private/...`（需要登录 Access）
- 公开页面：引用 `wedding-public.example.com/public/...`（无需登录）

## 6. 验收清单

- `wedding.example.com` 未登录时不可访问（Access 生效）
- 登录后可访问 `private/` 下图片
- （可选）`wedding-public.example.com/public/...` 可匿名访问
- 图片 URL 稳定，网站加载正常

## 7. 备份

至少备份：

- `/srv/data/wedding`
- `docker-compose.yml`

建议每月抽样恢复一批图片，验证可重新对外提供访问。
