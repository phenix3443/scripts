## 落地目标

在 OMV 上部署 Nextcloud，并通过 Cloudflare Tunnel 提供外网 HTTPS 访问，实现网盘替代能力。

## 1. 前置准备

### 1.1 共享目录

在 OMV 上准备：

- `/srv/data/files`
- `/srv/data/appdata/nextcloud`
- `/srv/data/appdata/compose/nextcloud`

### 1.2 域名规划

- `drive.example.com` → Nextcloud

## 2. 部署 Nextcloud（Docker Compose）

在 `/srv/data/appdata/compose/nextcloud/docker-compose.yml`：

```yaml
services:
  db:
    image: mariadb:11
    restart: unless-stopped
    environment:
      - MYSQL_ROOT_PASSWORD=${MYSQL_ROOT_PASSWORD}
      - MYSQL_DATABASE=nextcloud
      - MYSQL_USER=nextcloud
      - MYSQL_PASSWORD=${MYSQL_PASSWORD}
    volumes:
      - /srv/data/appdata/nextcloud/db:/var/lib/mysql

  redis:
    image: redis:7
    restart: unless-stopped

  nextcloud:
    image: nextcloud:29
    restart: unless-stopped
    depends_on:
      - db
      - redis
    environment:
      - MYSQL_HOST=db
      - MYSQL_DATABASE=nextcloud
      - MYSQL_USER=nextcloud
      - MYSQL_PASSWORD=${MYSQL_PASSWORD}
      - REDIS_HOST=redis
    volumes:
      - /srv/data/appdata/nextcloud/html:/var/www/html
      - /srv/data/files:/var/www/html/data
```

在同目录创建 `.env`：

```env
MYSQL_ROOT_PASSWORD=CHANGE_ME
MYSQL_PASSWORD=CHANGE_ME
```

启动：

```bash
cd /srv/data/appdata/compose/nextcloud
docker compose up -d
```

## 3. 部署 Cloudflare Tunnel（对外访问）

### 3.1 创建 Tunnel

Cloudflare Zero Trust → Networks → Tunnels → Create Tunnel，拿到 `TUNNEL_TOKEN`。

### 3.2 运行 cloudflared（容器）

在 `/srv/data/appdata/compose/cloudflared/docker-compose.yml`：

```yaml
services:
  cloudflared:
    image: cloudflare/cloudflared:latest
    restart: unless-stopped
    command: tunnel run
    environment:
      - TUNNEL_TOKEN=${TUNNEL_TOKEN}
```

`.env`：

```env
TUNNEL_TOKEN=YOUR_TUNNEL_TOKEN
```

启动：

```bash
cd /srv/data/appdata/compose/cloudflared
docker compose up -d
```

### 3.3 配置 Public Hostname

在 Tunnel → Public Hostnames 添加：

- Hostname：`drive.example.com`
- Service：`http://nextcloud:80`

注意：cloudflared 与 nextcloud 需要在同一 Docker network，或改成指向宿主机端口/地址。建议统一一个 compose 项目级 network（按你的实际部署方式调整）。

## 4. 初始化与使用

- 浏览器打开 `https://drive.example.com` 完成初始化
- 创建你与老婆账号
- 配置共享目录
- 安装客户端：
  - Nextcloud Desktop（电脑同步）
  - Nextcloud Mobile（手机访问/上传）

## 5. 验收清单

- 外网可通过 HTTPS 打开登录页
- 电脑端目录同步正常（含断点续传）
- 手机端可上传/下载
- 共享文件夹对两人账号可见且权限正确
- 回收站/版本可恢复文件
